# Pacman

Starter project for a Pacman game written in Go using
[Ebitengine (Ebiten)](https://ebitengine.org/).

Currently, it opens a black window titled `Pacman`, with a game area
of **224 pixels wide by 288 pixels high**. Both the internal resolution
and the initial window size are 224 x 288.
On HiDPI displays, the operating system may apply its own scaling factor.
Game logic is not implemented yet.

## Requirements

- Go 1.22 or later.
- A desktop environment with OpenGL graphics support.
- On Linux: a C compiler and the development libraries required by Ebitengine.

On Debian/Ubuntu, install the native dependencies with:

```sh
sudo apt install build-essential libasound2-dev libxcursor-dev libxi-dev libxinerama-dev libxrandr-dev libgl1-mesa-dev libxxf86vm-dev pkg-config
```

For other platforms, see the
[installation guide](https://ebitengine.org/en/documents/install.html).

## Running

From the project directory:

```sh
go mod tidy
go run .
```

The first command downloads dependencies and generates `go.sum`.
To exit, close the window.

## Building

```sh
go build -o pacman .
./pacman
```

## Project Structure

- `main.go`: window setup and game loop (`Update`, `Draw`, `Layout`).
- `go.mod`: Go module and Ebitengine version.
- `go.sum`: dependency checksums, generated by `go mod tidy`.
